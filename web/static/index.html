Connect Figma

  1. Build the plugin

    In a terminal, from the project folder:

    cd figma_plugin && npm install && npm run build

  2. Import it into Figma Desktop

    Plugins are desktop-only. Go to Plugins → Development → Import plugin from manifest… and pick:

    —

  3. Open a design file and run it

    Use the design editor — Dev Mode is read-only, so edits fail there. Then Plugins → Development → Figma Designer Agent. Keep its window open.

  4. Confirm

    The plugin connects to —. Once it does, the file appears in your gallery automatically.
