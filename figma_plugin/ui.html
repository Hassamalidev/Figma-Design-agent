Not connecting? Read this
  1. Start the agent first: run python webapp.py in the project folder.
  2. Keep this plugin window open for the whole run — closing it drops the connection.
  3. Use the design editor, not Dev Mode. Dev Mode is read-only, so edits fail.
  4. If you changed the port, the URL above and networkAccess in manifest.json must both match — Figma blocks any host not listed there.
  5. Reconnects are automatic; this panel retries every couple of seconds.
